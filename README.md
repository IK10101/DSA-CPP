# DSA in C++

This repository contains my Data Structures and Algorithms practice in C++.

## Topics Covered
- Arrays
- Hashing
- Binary Search
- Linked Lists
- Recursion
- Greedy Algorithms
  - Hard Problems (Candy, Valid Parentheses String)
  - Scheduling and Interval Problems (Job Sequencing, N Meetings in One Room, Shortest Job First)
- Stacks
  - Monotonic Stack (Asteroid Collision, Next Greater Element I & II, Remove K-Digits, Sum of Subarray Minimums, Sum of Subarray Ranges)
  - Queue/Stack Implementations using Array, Linked List, Stack, and Queue
  - VVImp Problems (Implement Min Stack, Sliding Window Maximum)
- Two Pointer / Sliding Window
  - Constant Window (Maximum Points You Can Obtain from Cards)
  - Variable Window / Counting Subarrays (Binary Subarrays With Sum, Count Nice Subarrays, Fruit Into Baskets, Longest Repeating Character Replacement, Longest Substring With At Most K Distinct Characters, Longest Substring Without Repeating Characters, Max Consecutive Ones III, Minimum Window Substring, Number of Substrings Containing All Three Characters)

## Goal
- Strengthen problem-solving skills
- Prepare for coding interviews
- Maintain consistency in DSA practice

## Platforms
- LeetCode
- TakeUforward
